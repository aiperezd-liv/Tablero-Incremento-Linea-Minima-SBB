# Project Design & Memory: Test_linea_minima_V1

## Overview
This state documents the baseline version **Test_linea_minima_V1** for the **Test Incremento Línea Mínima (SBB Departamental)**.

### Version Key Features
- **Design Name**: `Test_linea_minima_V1`
- **Brand Palette (Suburbia)**:
  - **Primary Purple / Morado Suburbia**: `#51186B`
  - **Vibrant Magenta / Rosa Suburbia**: `#E3007B`
  - **Soft Neutral Backgrounds**: `#faf5ff`, `#fdf2f8`, `#f8fafc`
  - **High-contrast typography**: Dark purple headers and crisp slate body text.
- **Scorecards Formatting (Líneas Promedio)**:
  - Struck-through text format (`line-through`) was completely removed.
  - Replaced with clean dual-metric comparison cards showing "Línea Promedio Esperada" prominently alongside a sub-badge displaying "Línea Actual Base" and delta percentages (`+$203 (+1.16%)` for HIT, `+$907 (+26.41%)` for NO HIT, `+$555 (+5.30%)` for Total).
- **Bad Rates Labels**:
  - Simplified label from `"Esperado (xStress 30%)"` to strictly `"Esperado"`.
- **Core Business Rule**:
  - Test proposal for elevating minimum credit line from $2,000 to $4,000 MXN for applicants with total income > $4,000 MXN.
